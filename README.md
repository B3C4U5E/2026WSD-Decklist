# 2026WSD-Decklist
Jack Simon
## Idea
Most of the deckbuilders around today have a collection feature, but they are secondary to the deckbuilding feature. This project is supposed to be collection-first focused instead of deck-first. I plan to focus on *Magic: the Gathering*, but I expect that it will be easy to adapt this to other trading card games like *Pokémon* or *Yu-Gi-Oh!*.
## Target Users
The target users of this program are TCG hobbyists who want to build decks with cards they have instead instead of spending money to buy new cards.
## Major Features
- The users will be able to build their own decks using the existing MTG/Scryfall API.
- The users will be able to track their collection using the existing MTG/Scryfall API.
- The users' collection will track which decks each card is in.
- The users will be able to add cards to their collection when adding them to their decks.
- The users will be able to move cards between decks.
- When adding cards from the users' collection to one of their decks, the search will prioritize cards in their collection that are not in any deck over cards that are in other, existing decks.
